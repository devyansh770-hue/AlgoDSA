📝 Custom Study Notes & Reminders

This section renders study notes, custom algorithms, and revision key points. You can add notes for any topic!

📌 Master Solving Workflow:
  1. Understand Constraints: If $N \le 10^5$, aim for $O(N)$ or $O(N \log N)$ algorithm. Avoid $O(N^2)$.
  2. Identify Pattern: Sorted array? Try Binary Search or Two Pointers. Subarray bounds? Try Sliding Window. Hierarchy / Folders? Try Tree DFS / BFS. Shortest path? Try Graph BFS / Dijkstra.
  3. Write Pseudocode / Explain It Back: Explain the logic before writing code.
  4. Edge Cases: Check empty array, 1 element, all duplicates, negative numbers, overflow.
