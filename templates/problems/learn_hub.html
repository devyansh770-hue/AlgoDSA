📌 Master FAANG Solving Workflow

1. Analyze Constraints

If N ≤ 10⁵, aim for O(N) or O(N log N). If N ≤ 20, O(2ᴺ) backtracking is acceptable. Avoid O(N²) for large N.

2. Identify Pattern

Sorted array? Binary Search. Subarray bounds? Sliding Window. Subsets / Combinations? Backtracking. Shortest path? BFS.

3. Dry Run & Pseudocode

Dry run pointers on a sample array (e.g. `[1, 2, 4, 7]`) on paper/board before typing code in Monaco editor.

4. Verify Edge Cases

Check empty inputs, 1 element arrays, all duplicates, negative numbers, and potential integer overflow.
