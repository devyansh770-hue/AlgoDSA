When & Why To Use (Triggers vs Anti-Signals)

When TO Use This Pattern
  • Problem asks for contiguous subarrays/substrings or bounds.
  • Target metric involves Min/Max, Sum, or K distinct elements.
  • Input structure is sorted or can be partitioned.
  • Requires optimizing brute force $O(N^2)$ to linear $O(N)$ time.
When NOT To Use
  • Elements do not need to be contiguous (subsequences).
  • Data structure cannot be indexed or traversed sequentially.
  • Requires generating all subsets/permutations (Use Backtracking).
  • Negative weights present in shortest path queries (Use Bellman-Ford).

# 2. Shrink left boundary
