⚡ Core Concept & Time Complexities

{% if topic.slug == 'arrays' %}

Array is a linear data structure containing contiguous memory blocks. Every element can be accessed in O(1) time using its index.

  • Access: O(1)
  • Search: O(N) linear search, O(log N) binary search on sorted array
  • Insertion / Deletion: O(N) due to element shifting
{% elif topic.slug == 'linked-lists' %}

Linked List consists of nodes where each node contains a value and a pointer (reference) to the next node in memory.

  • Access / Search: O(N) (must traverse from head)
  • Insertion / Deletion: O(1) if pointer to node is already known
  • Types: Singly Linked List, Doubly Linked List, Circular Linked List
{% elif topic.slug == 'trees' %}

Tree is a hierarchical data structure consisting of nodes connected by edges. A Binary Tree has at most 2 children per node.

  • BST Search: O(log N) average, O(N) worst case (unbalanced)
  • Traversals: Inorder (Left-Root-Right), Preorder (Root-Left-Right), Postorder (Left-Right-Root), Level-Order (BFS)
{% elif topic.slug == 'graphs' %}

Graph consists of vertices (nodes) $V$ and edges $E$. Can be directed or undirected, weighted or unweighted.

  • BFS (Breadth-First Search): Shortest path in unweighted graphs using Queue — O(V + E)
  • DFS (Depth-First Search): Explore deep paths using Recursion/Stack — O(V + E)
{% elif topic.slug == 'dynamic-programming' %}

Dynamic Programming (DP) solves complex optimization problems by breaking them into overlapping subproblems and memoizing results.

  • Top-Down: Recursion + Memoization (HashMap / Array)
  • Bottom-Up: Iterative Tabulation table

def is_valid_palindrome(s: str) -> bool:
    left, right = 0, len(s) - 1
    while left < right:
        while left < right and not s[left].isalnum():
            left += 1
        while left < right and not s[right].isalnum():
            right -= 1
        if s[left].lower() != s[right].lower():
            return False
        left, right = left + 1, right - 1
    return True

        curr = nums[left] + nums[right]

from collections import deque

def bfs(graph, start):
    visited = {start}
    queue = deque([start])
    while queue:
        node = queue.popleft()
        for neighbor in graph.get(node, []):
            if neighbor not in visited:
                visited.add(neighbor)
                queue.append(neighbor)

def fib_dp(n: int, memo: dict = {}) -> int:
    if n <= 1: return n
    if n in memo: return memo[n]
    memo[n] = fib_dp(n - 1, memo) + fib_dp(n - 2, memo)
    return memo[n]

{% elif topic.slug == 'graphs' %}// Graph BFS Traversal Pattern
function bfsGraph(graph, start) {
    const visited = new Set([start]);
    const queue = [start];
    const result = [];
    while (queue.length > 0) {
        const node = queue.shift();
        result.push(node);
        for (const neighbor of (graph[node] || [])) {
            if (!visited.has(neighbor)) {
                visited.add(neighbor);
                queue.push(neighbor);
            }
        }
    }
    return result;
}

            left++; right--;
        }
        return true;
    }
}

{% elif topic.slug == 'graphs' %}// Java Graph BFS Traversal Pattern
import java.util.*;

public class Solution {
    public List bfsGraph(int start, List> adj) {
        List result = new ArrayList<>();
        Set visited = new HashSet<>();
        Queue queue = new LinkedList<>();
        visited.add(start);
        queue.add(start);
        while (!queue.isEmpty()) {
            int node = queue.poll();
            result.add(node);
            for (int neighbor : adj.get(node)) {
                if (!visited.contains(neighbor)) {
                    visited.add(neighbor);
                    queue.add(neighbor);
                }
            }
        }
        return result;
    }
}
